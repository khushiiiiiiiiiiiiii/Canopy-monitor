How this works

Soil moisture, air temperature, and humidity readings arrive from sensor nodes over /api/ingest, land in MongoDB, and feed a TensorFlow model that learns each zone's drying rate to predict when the next watering cycle is actually needed — instead of watering on a fixed timer.

A demo simulator is generating readings right now so you can see the system live. Point real ESP32 + soil moisture/DHT22 sensor hardware at /api/ingest and set IVF_USE_SIMULATOR=0 to switch over.
